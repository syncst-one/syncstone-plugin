Beta for testers (via BRAT). Everything from 0.3.2-beta.1, plus:

## What's new

**Faster sync**
- Files that have not changed are skipped, so a full sync takes seconds instead of a minute, especially on phones.
- Small and new files go first, a few at a time.
- The sync button still checks every file. A full check also runs once a day.

**"Sync finished" means finished**
- If a sync is already running when you press the sync button, Syncstone waits for it and says "Sync already running …". "Sync finished" only comes once everything is done.
- The first sync of a vault on a device tells you when it is done and how many files it has.

**Clearer version history**
- Edits made in one go show as one entry, e.g. "14:02–14:47 · 12 versions". The arrow shows the single versions.
- Restores, renames and deletes always keep their own entry.
- When you edit a note together live, the history shows who wrote it, not only the device that saved it. One live session no longer splits into many entries when someone leaves.

**Signing out**
- If this device is signed out from the browser or by an admin, the plugin signs out too and shows it in the settings. The linked vault stays.

## Please try
- A first sync on a phone: the message should only come at the very end.
- Edit a note together live, then look at the version history: both names, one entry.

The names in the version history need the newest server. With an older server the history looks as before.
