## What's new

**Sync you can rely on**
- When two devices change the same note, the changes are merged instead of one overwriting the other. If both changed the same lines, the other version is kept as a copy.
- What you type is never overwritten, also on a poor connection or while a change from another device is still coming in.
- Editing a note now wins over deleting it on another device, so your edit is never lost.
- Renaming a note while it is being edited no longer leaves two files behind.
- Editing together live: changes from devices outside the session are merged into the open note.

**Safer deletes**
- If more than 5 files went missing while Syncstone was not running, Syncstone asks whether to delete them everywhere or bring them back.
- Files deleted on Android now reach your other devices.

**Upper and lower case in names**
- Notes whose names differ only in case, such as "Test" and "test", are handled correctly on every system. Changing only the case of a name is followed on all devices.
- Conflict copies are named "(conflict date time)".

**Settings sync**
- Before settings are synced for the first time, Syncstone asks once which device's settings count. Plugin settings from both sides are combined.
- Deleting a plugin, theme or snippet deletes it on all devices.
- Community plugins are only synced if you turn it on.

**Clearer first sync**
- The first sync dialog says in one line that both sides are merged.

## Also improved on the service
- The device list shows the Syncstone version of each device and when an update is available.
- The web app also merges changes instead of overwriting them.
- On phones, the web app has a tab overview with previews and a smoother side menu.
- A new note in the web app starts with its title selected.
